Provider marks are bundled locally so project identity works offline and does
not request third-party images while using a workspace.

- `gemini.svg`: the four-color spark from the [official Gemini site](https://gemini.google/about/), cropped from its wordmark without changing the mark.
- `codex.svg`: the OpenAI knot from the [official Codex documentation](https://developers.openai.com/codex/), rendered in the foreground color for each theme.

These marks identify the selected agent; they do not imply affiliation.
